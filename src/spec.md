# Specification

## Summary
**Goal:** Deliver a minimal “Aurise” landing page with a cohesive dark fantasy aura-inspired visual theme, including a smooth animated aura effect and custom static theme assets.

**Planned changes:**
- Create a single landing page application shell that prominently displays the title “Aurise” with no placeholder/lorem text.
- Apply a consistent dark, high-contrast “aura” theme across layout, typography, headings, and any buttons/accents (English-only UI text).
- Add an animated aura visual effect (e.g., pulsing glow/particle haze/energy ring) that runs smoothly without blocking interaction and respects reduced-motion preferences.
- Generate and include custom static image assets (background + emblem/logo) under `frontend/public/assets/generated` and reference them directly from the frontend.

**User-visible outcome:** Users see an “Aurise” landing page with a dark, glowing aura aesthetic, a smooth aura animation (with reduced-motion fallback), and integrated custom background and emblem imagery.
